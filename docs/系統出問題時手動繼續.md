# 系統出問題時手動繼續

這份文件寫給幹事：系統壞了、Web App 打不開、或者你趕時間不想等人修理，
怎樣在 Google Drive 找到這一季**最新版**的職事表，自己手動改、自己寄出，
之後系統回復時又怎樣把你手改的那一版讀回系統，繼續用介面。

**總原則**：系統每一次儲存版本都會把內容放到 Drive 三個地方。你**不需要**
進入系統本身，也**不需要**看 `RosterAssignments` 那些工作表。

（這份文件在公開 repo，所以沒有真實的網址、試算表 ID 或人名。實際連結在
Web App「進階與診斷 ▸ 系統出問題時怎樣做」會由系統讀出來顯示。）

---

## 一、去哪裡找最新版

| 位置 | 內容 | 可以改嗎 | 幾時更新 |
|---|---|---|---|
| **公開連結試算表** | 整季表（崗位做列、日期做欄），義工電郵裡那條連結就是它 | 不可以（唯讀分享） | 每次「儲存及寄出」、每次填講員之後自動更新 |
| **完整版 PDF** | 整季表的 PDF，一版一份 | 不可以 | 每次正式發出、每次產生 PDF |
| **可編輯的試算表副本** | 最新版本的 grid 工作表（連顏色、圖例、本季服侍次數統計）複製成一份獨立試算表 | **可以** | 正式發出成功之後自動做一份；第 4 步「下載及匯出」可以隨時再做 |

三個都在同一個 Shared Drive 資料夾（Config 的 `ROSTER_DRIVE_FOLDER_ID` 指向那個
資料夾）：

```
<PDF 根資料夾>/
  <季度>/
    v<N>/              ← 第 N 版的 PDF（完整版 + 個人版）
    可編輯副本/         ← <季度>_第<N>版_職事表_可編輯副本_<yyyyMMdd-HHmm>
```

檔名尾的時間戳令你一眼看到哪一份最新；系統自己也是靠檔名排序。

在 Web App 的「進階與診斷 ▸ 系統出問題時怎樣做」可以直接開這三個位置
（連結由程式讀出來，不是寫死的）。Web App 打不開的話，直接開 Shared Drive
找上面那個資料夾結構就可以。

---

## 二、怎樣複製一份自己改

### 有「可編輯副本」

1. 打開 `<季度>/可編輯副本/` 裡**檔名時間戳最新**那一份。
2. 它已經是一份獨立試算表，直接改格子就可以。第 2 行（機器鍵）是隱藏的，不要
   把它解除隱藏再改——匯入的時候系統靠它認崗位。
3. 想保留原本那份的話，先「檔案 ▸ 建立副本」再改副本。

### 沒有「可編輯副本」（例如那一季從未正式發出過）

1. 打開公開連結試算表。
2. 「檔案 ▸ 建立副本」存到你自己可以改的地方。
3. 這一份是崗位做列、日期做欄的版面，沒有顏色和統計，但內容是最新已儲存版本。

⚠️ 不要在系統自己那個試算表（有 `Roster_<季度>_v<N>` 工作表那個）直接改。
系統回復之後會把你的改動當成「未儲存的人手改動」處理，流程會混亂。

---

## 三、改完之後怎樣寄

- 直接把你改好的試算表「檔案 ▸ 分享」或者「下載 ▸ PDF」寄給義工／印出來。
- 這段時間系統裡的版本**不會**跟著變。義工電郵裡的公開連結仍然顯示系統
  最後儲存那一版——如果你怕有人看舊的，寄出時在信裡講清楚「以附件為準」。

---

## 四、系統回復之後怎樣回到系統

用「匯入人手職事表」（Web App「進階與診斷」，第六十七輪 AF 組）：

1. 在「進階與診斷 ▸ 匯入人手職事表」按「建立匯入表」。系統會在試算表裡建一張
   `匯入_<季度>` 工作表：一行一個崗位格、一欄一個主日，每格有名單下拉選單
   （容許打不在名單上的名字，匯入時會逐個問你）。灰色「—」的格是那一週不設
   那個崗位，不用填。
2. 把你手改那一版的名字抄進去（可以整欄複製貼上）。
3. 按「檢查」：認不出的名字會逐個列出來（要先改成正確寫法或者加人）；違反一定
   要遵守的規則會列出來，要你打字放行；空格會提醒但不阻擋。
4. 按「匯入」：系統會建立一個新版本（來源寫「由人手職事表匯入」），全部格都當
   成你親手填的，公開連結會自動更新。
5. 如果你**已經在系統外把這一版寄給全體**，匯入時勾「已經在系統外寄給全體」。
   系統會把這一季記成「已正式發出」，之後改動只會寄給有改動的人（第 5 步），
   不會再把整季寄一次。
6. 之後照常用介面：改表、請系統幫我調整、儲存及寄出、改動後重發。

如果 AF 組還未部署（「進階與診斷」沒有「匯入人手職事表」），暫時只能把你改
的格子逐格抄回系統的 grid 工作表，再按「儲存及寄出」——那會被當成人手改動，
一樣會經過規則檢查。
